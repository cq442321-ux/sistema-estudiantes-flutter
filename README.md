# Sistema de Gestión de Estudiantes 📚

Aplicación móvil desarrollada con Flutter para registrar y consultar información de estudiantes.

Tecnologías
- Flutter
- Dart
- PHP
- MySQL

Funcionalidades
- Registro de estudiantes.
- Consulta de estudiantes.
- Visualización de información.
