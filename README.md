# 📚 Sistema de Gestión de Estudiantes

Aplicación móvil desarrollada con **Flutter y Dart**, conectada a una API REST creada en **PHP** y una base de datos **MySQL**.

Este proyecto permite registrar y consultar información de estudiantes desde una interfaz móvil.

## 🚀 Tecnologías utilizadas

- Flutter
- Dart
- PHP
- MySQL
- XAMPP
- API REST
- Git y GitHub

## ✨ Funcionalidades

- Registro de estudiantes.
- Consulta de estudiantes registrados.
- Visualización de información en una lista.
- Validación de campos obligatorios.
- Comunicación entre Flutter y PHP mediante solicitudes HTTP.
- Envío y recepción de datos en formato JSON.

## 🗂️ Estructura del proyecto

- `lib/`: código fuente de la aplicación Flutter.
- `api_php/`: archivo PHP encargado de gestionar las solicitudes de la aplicación.
- `android/`, `ios/`, `web/`: plataformas compatibles con Flutter.

## 🛠️ Requisitos para ejecutar el proyecto

- Flutter instalado.
- Dart.
- XAMPP con Apache y MySQL.
- Base de datos configurada.
- API PHP configurada en el servidor local.
